# Loop

Static, responsive homepage mockup for **Loop**, a social app — stories, photo feed, clips and videos.

Live: https://h42506916-web.github.io/loop/

Plain HTML/CSS/JS with no build step. Open `index.html` locally or serve the folder with any static server.

- `index.html`: page shell
- `styles.css`: styles (local fonts in `assets/fonts`)
- `app.js`: renders the UI from mock data
- `assets/`: logo, images, fonts
